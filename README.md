# VibeCheck 

VibeCheck is a music mood journal developed as a software engineering capstone project. 

## Features 
- Music and mood journaling (planned) 
- SQLite database (planned) 
- Local AI mood reflection using Ollama (planned)

## Technologies 
- Python 
- Flask 
- HTML and CSS 
- SQLite
- Ollama 
- Git and GitHub 

## Running Locally 

1. Create a python virtual environment. 
2. Install dependencies from requirements.txt. 
3. Run `python app.py`.
4. Visit http://127.0.0.1:5000.
